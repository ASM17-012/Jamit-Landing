第1章総則

第1条目的 #

本規約は、김민재（以下「運営者」という。お問い合わせ：support@jamit.kr）が 提供するモバイルアプリケーションサービス「JAMIT」（以下「本サービス」という。）の利用に関し、運営者と会員との間の 権利、義務及び責任事項、本サービスの利用条件及び手続、その他必要な事項を定めることを目的とする。

第2条定義 #

本規約において使用する用語の意味は、次のとおりとする。

  1. 「本サービス」とは、YouTubeに公開された原曲の特定の区間を基準として、会員がパート（楽器・ボーカル等）ごとの 演奏動画をアップロードしてセッションを完成させ、参加したトラックを組み合わせたItsを作成・保存・共有できるよう 運営者が提供するJAMITモバイルアプリケーション及び関連する一切のサービスをいう。
  2. 「会員」とは、本規約に同意し、ソーシャルログインを通じて利用契約を締結して本サービスを利用する者をいう。
  3. 「原曲」とは、セッションの基準となる、YouTubeに公開された音楽動画コンテンツをいう。 原曲は本サービスが保存・配信するものではなく、YouTubeを通じて再生される。
  4. 「募集投稿」（又は「ジャム」）とは、会員が原曲の特定の区間及び募集するパートを指定して セッションの参加者を募集する投稿をいう。
  5. 「トラック」とは、会員が募集投稿に参加するために撮影・アップロードするパートごとの演奏動画（映像及び音声を含む。）をいう。
  6. 「Its」とは、一つの募集投稿に集まったトラックを組み合わせてグリッド形式等で合成した短い動画をいい、 作成者はこれを端末に保存し、又は本サービスの外部に共有することができる。
  7. 「チャット」とは、会員が他の会員と本サービス内でメッセージをやり取りする機能をいい、 2人の会員の間の会話及び複数の会員が参加するチャットルーム（スペースに付属するチャットルームを含む。）のいずれも含む。
  8. 「メッセージ」とは、会員がチャットで送信するテキスト及びメッセージに添えて共有する 募集投稿・トラック・Itsをいう。
  9. 「コンテンツ」とは、会員が本サービスに投稿・アップロードした募集投稿、トラック、Its、プロフィール、テキスト、 メッセージ等の一切の資料をいう。

第3条規約の掲示及び改定 #

  1. 運営者は、本規約の内容を会員が容易に確認できるよう、本サービス内の画面及び案内ページに掲示する。
  2. 運営者は、「約款の規制に関する法律」（약관의 규제에 관한 법률）、「情報通信網利用促進及び情報保護等に関する法律」（정보통신망 이용촉진 및 정보보호 등에 관한 법률）等の関係法令に 違反しない範囲で、本規約を改定することができる。
  3. 本規約を改定する場合は、適用日及び改定理由を明示して、適用日の7日前から（会員に不利な変更又は重大な変更の 場合は30日前から）本サービス内のお知らせ又はプッシュ通知等により告知する。
  4. 会員が改定後の規約の適用日以降も本サービスを継続して利用する場合は、改定後の規約に同意したものとみなす。 改定後の規約に同意しない会員は、第7条に従い退会することができる。

第4条規約外の準則 #

本規約に定めのない事項及び本規約の解釈については、関係法令及び一般的な商慣習に従う。 個人情報の取扱いに関する事項は、別途定める「JAMIT プライバシーポリシー」に従う。なお、本規約において法令名を掲げる場合、大韓民国の法令をいう。

第2章利用契約とアカウント

第5条利用契約の締結 #

  1. 利用契約は、本サービスを利用しようとする者がKakao、Google、Appleのアカウントによるソーシャルログインで登録を申し込んだ後、 本規約及びプライバシーポリシーにそれぞれ同意し、運営者がこれを承諾することにより成立する。 本規約に同意しない限り、本サービスに登録することはできない。
  2. 本サービスには、満14歳以上の者のみ登録することができる。運営者は、満14歳未満であることが確認されたアカウントについて、 利用契約を解除することができる。
  3. 本規約への同意には、第16条の 不適切なコンテンツ及び悪質な利用者に対する不寛容（zero-tolerance）の原則への同意が含まれる。
  4. 運営者は、次の各号のいずれかに該当する申込みについて、承諾を拒否し、又は事後に利用契約を解除することができる。
    1. 過去に第16条又は第19条に基づき 本サービスから排除された者が再度登録を申し込む場合
    2. 他人のソーシャルアカウントを盗用した場合
    3. 不正な目的又は方法により申し込んだ場合

第6条アカウント及び会員情報の管理 #

  1. アカウントは会員本人のみが利用することができ、他人に譲渡・貸与することはできない。
  2. 会員は、自己のソーシャルアカウント及び端末の管理について責任を負い、第三者による無断使用を知った場合は、直ちに運営者に 通知しなければならない。会員の管理不十分により生じた不利益について、運営者は故意又は過失がない限り責任を負わない。
  3. 会員は、プロフィール等の会員情報に変更があった場合、本サービス内でこれを修正しなければならない。

第7条退会 #

  1. 会員は、いつでもアプリ内の退会機能により利用契約を解除（退会）することができる。
  2. 退会時、運営者はログインセッション及びプッシュトークンを無効化し、ソーシャルログイン連携（Kakao・Google・Apple）の解除も あわせて処理する。Appleアカウントは連携解除が完了しなければ退会が処理されず、Kakao・Googleアカウントは、連携解除の 要求が失敗し、又はアプリの環境において解除がサポートされていない場合であっても、運営者が保管していた連携情報が破棄される。 会員は各プラットフォームのアカウント設定から直接連携を解除することができ、詳細な取扱いは プライバシーポリシー第7条に従う。
  3. 退会した会員の個人情報は、「JAMIT プライバシーポリシー」に定めるところにより破棄される。 退会すると、会員が送信したメッセージは相手方の画面に表示されなくなり、複数人が参加した チャットルームに残っている者が誰もいなくなった場合、そのルームのメッセージは他の会員が書いたものも含め、同じ手続に 従う。保管期間は、プライバシーポリシー第3条に従う。
  4. 退会した会員がアップロードしたコンテンツ（トラック・募集投稿・Its）の取扱いは、次のとおりとする。
    1. 会員がアップロードしたトラック（オリジナル・補正版・サムネイル）は、退会とともに本サービス上で表示されなくなり、 プライバシーポリシー第3条に定める期間の経過後に 破棄される。
    2. 会員が作成したItsは、公開の有無にかかわらず、同様の方法で取り扱われる。他の会員が作成したItsは、 会員のトラックが含まれている場合であっても維持される（第14条第4項）。
    3. 会員が作成した募集投稿は、他の会員のトラック又はItsが残っている場合、作成者を「不明」と 表示したまま維持され、この場合、会員がアップロードした参考動画は募集投稿から切り離され、第1号と同様の方法で取り扱われる。 他の会員のコンテンツがない募集投稿は、第1号と同様の方法で取り扱われる。
  5. 本サービスの外部（SNS等）に既に共有・保存されたItsは、運営者の管理の範囲外であるため、運営者はその回収・削除を 保証することができない。
  6. 退会後30日間は、同一のソーシャルアカウントで再登録することはできない。 第19条に基づく利用停止中に退会した場合は、当該利用停止期間が終了するまで（最長1年） 再登録することはできない。このために運営者が保管する情報及び期間は、 「JAMIT プライバシーポリシー」第3条に従う。

第3章本サービスの利用

第8条本サービスの内容 #

  1. 運営者は、次のサービスを提供する。
    1. 原曲の区間に基づくセッションの募集投稿の作成・探索・参加
    2. パートごとのトラック動画の撮影・アップロード（端末のカメラ・マイクを利用）及び自動同期補正
    3. 参加トラックを組み合わせたItsの合成・再生・端末への保存・外部への共有
    4. 会員間のチャット — メッセージの送達・保管、既読状態の表示、チャットルームの参加者の管理
    5. プロフィール、通知、報告・ブロック等の付加機能
  2. 本サービスは無料で提供される。有料サービスを導入する場合は、別途告知し、同意を得る。
  3. 本サービスは年中無休での提供を原則とするが、点検等の運営上の必要により一時的に中断されることがある。

第9条原曲の再生とYouTubeサービス #

  1. 原曲はYouTubeが提供するプレーヤーを通じて再生され、その利用には YouTubeの利用規約が適用される。会員は、本サービスを利用することにより、 YouTubeの利用規約に同意したものとする。YouTubeの利用過程における個人情報の取扱いは、 プライバシーポリシー第10条に従う。
  2. 運営者は原曲の権利者ではなく、原曲が削除され、非公開とされ、又は埋め込みが制限される等のYouTube側の事情により、 関連する募集投稿・機能の利用が制限されることがある。この場合、運営者は故意又は過失がない限り責任を負わない。

第10条通知 #

  1. 運営者は、セッションへの参加、Itsの公開、チャットメッセージの受信等、本サービスの利用に必要な通知を アプリのプッシュ通知により送信することができる。チャットの通知には、送信した会員のニックネーム及びメッセージ内容の冒頭部分が表示されることがある。
  2. 会員は、端末の設定又は本サービス内の設定により、プッシュ通知の受信を拒否することができる。ただし、本サービスの運営に関する 重要なお知らせは、プッシュ通知以外の方法によっても案内されることがある。

第11条本サービスの変更及び中断 #

  1. 運営者は、運営上・技術上の必要に応じて本サービスの全部又は一部を変更することができ、重要な変更は事前に 本サービス内で告知する。
  2. 運営者は、次の場合、本サービスの提供を一時的に中断することができる。
    1. システムの点検・保守・交換
    2. 停電、設備の障害、アクセスの集中、電気通信事業者又はクラウド事業者のサービスの中断
    3. 天災地変、国家非常事態等の不可抗力
  3. 運営者が本サービスの提供を終局的に中止（サービス終了）しようとする場合は、終了日の30日前までに本サービス内のお知らせ等により 告知する。この場合、会員は、終了日までに自己のItsを端末に保存する等の方法によりコンテンツをバックアップすることができる。
  4. 無料で提供される本サービスの変更・中断により生じた損害について、運営者は故意又は重大な過失がない限り 責任を負わない。

第13条コンテンツの利用許諾 #

  1. 会員は、自己が投稿したコンテンツについて、運営者に対し、本サービスの提供・運営・改善のために必要な範囲でこれを 保存・複製・エンコード・合成（トラックの同期補正及びItsのグリッド合成を含む。）・表示・送信し、並びに本サービスの品質及び 使いやすさの改善のために運営者の内部で閲覧・分析することができる非独占的な利用権を許諾する。内部での閲覧・分析の 目的及び範囲は、プライバシーポリシー第1条に従う。
  2. 第1項の利用権には、本サービスの宣伝を目的とする利用は含まれない。運営者が会員の コンテンツを本サービスの宣伝目的（広告、外部チャンネルへの掲載、アプリストアの紹介資料等）で利用しようとする場合は、事前に当該 会員の同意を得るものとし、セッションのItsのように複数の会員のコンテンツがともに含まれる場合は、各会員の同意を得る。

  4. 第1項の利用権は、会員が当該コンテンツを削除し、又は退会したときに終了する。ただし、 第7条第4項の退会時のコンテンツの取扱方針及び既に合成されたItsについては、 当該条項が優先し、削除・退会したコンテンツを報告の審査のために一定期間保管する範囲においては、 プライバシーポリシー第3条が優先する。

第14条セッションへの参加と肖像・音声・実演に関する同意 #

  1. トラックには、会員の顔・身体・音声及び演奏の実演が含まれることがある。
  2. 会員が募集投稿にトラックをアップロードしてセッションに参加することは、次の各号に同意したものとみなす。
    1. 当該トラックが本サービス内で他の利用者に表示・再生されること
    2. 同じ募集投稿に参加した他の会員がItsを作成する際に、会員のトラック（会員の肖像・音声・実演を含む。）を 組合せに含めること
    3. そのように作成されたItsを、作成者が自己の端末に保存し、又は本サービスの外部（SNS等）に共有すること
  3. Itsの作成者は、自己がアップロードしたトラックを少なくとも1つ含めなければならず、他人のトラックのみでItsを 作成することはできない。
  4. 会員は、トラックを削除することにより、将来のItsの作成に対する同意を撤回することができる。ただし、削除以前に既に 作成されて端末に保存され、又は本サービスの外部に共有されたItsには及ばないことがある。 会員が退会した場合であっても、他の会員が作成したItsに含まれる会員のトラックは当該Itsとともに維持され、 会員はセッションへの参加時にこれに同意する。会員本人が作成したItsは、 第7条第4項第2号に従って取り扱われる。

第15条会員の義務及び禁止行為 #

  1. 会員は、関係法令、本規約及び本サービス内の案内事項を遵守しなければならない。
  2. 会員は、次の各号の行為をしてはならない。
    1. わいせつ物、性的対象化するコンテンツ、児童・青少年を対象とする一切の性的コンテンツの投稿
    2. 暴力的・残虐なコンテンツ、自傷・自殺を助長するコンテンツの投稿
    3. 特定の個人・集団に対する嫌悪、差別、侮辱、嫌がらせ、脅迫、ストーカー行為
    4. 他人の著作権・肖像権・個人情報等の権利を侵害するコンテンツの投稿（同意のない他人の撮影物を含む。）

    6. 広告・スパム、繰り返しの投稿、本サービスの目的と無関係なコンテンツの大量投稿
    7. 本サービスのソースコード・サーバー・APIへの不正アクセス、リバースエンジニアリング、自動化された手段を用いた不正利用
    8. チャットにおいて相手が望まないメッセージを繰り返し送信し、チャットルームに広告・スパムを 送信し、又は会話の内容を相手の同意なく外部に公開する行為
    9. 報告機能の悪用（虚偽の報告・繰り返しの報告）
    10. その他関係法令に違反し、又は公序良俗に反する行為

第16条不適切なコンテンツと悪質な利用者に対する不寛容の原則 #

  1. 運営者は、不適切なコンテンツ（objectionable content）及び悪質な（abusive）利用者に対して、 不寛容（zero-tolerance）の原則を適用する。
  2. 会員は、本サービス内の報告機能により、募集投稿、トラック、Its、メッセージ又は利用者を報告することが できる。会員は、第18条のブロック機能により特定の会員との1対1の チャットをブロックすることができ、複数人が参加するチャットルームでは、ブロックした会員と同じルームにとどまるが、 互いのメッセージが非表示となる。
  3. 運営者は、報告を受け付けた時から24時間以内に当該コンテンツを確認し、不適切なコンテンツであることが確認された場合は これを削除又は非表示とし、当該コンテンツを投稿した利用者を本サービスから排除（利用停止又は永久利用停止）する。 最初の確認以降の審査は、受付日から7営業日以内に終える。
  4. 運営者は、不適切なコンテンツが投稿されることを防止するための事前・事後のフィルタリング措置を運用することができる。 メッセージは本項の対象ではない — 運営者は、会員同士でやり取りされる会話の内容を、 報告なく閲覧しない（第13条第3項）。
  5. 本条に基づく措置に異議のある会員は、support@jamit.krを通じて 異議を申し立てることができ、運営者は確認の上、正当な理由がある場合は措置を解除する。

第17条権利侵害の報告及び掲載停止 #

  1. 自己の著作権、肖像権等の権利が会員のコンテンツにより侵害されていると主張する者（以下「権利主張者」という。）は、 その事実を疎明して、運営者に対し当該コンテンツの削除又は掲載停止を求めることができる。
  2. 運営者は、第1項の求めを受けた場合、「著作権法」（저작권법）第103条等の関係法令が定める手続に従い、遅滞なく当該 コンテンツを削除し、又はアクセスを遮断し、その旨をコンテンツの投稿者及び権利主張者に通知する。
  3. コンテンツの投稿者は、自己に正当な権利があることを疎明して掲載の再開を求めることができ、運営者は関係法令が 定める手続に従って処理する。
  4. 権利侵害の報告窓口：本サービス内の報告機能又はsupport@jamit.kr

第18条利用者のブロック機能 #

  1. 会員は他の利用者をブロックすることができ、ブロックした利用者のコンテンツは、会員のフィード、検索、通知等に表示されない。 チャットにおいては当該利用者との1対1のチャットが閉じられ、複数人が参加するチャットルームにおいては同じルームに とどまるが、互いのメッセージが非表示となる。ただし、演奏パート別のランキングには、ブロックの有無にかかわらず順位が表示される。
  2. ブロックは相手方に別途通知されず、会員はいつでもブロックを解除することができる。

第19条利用制限 #

  1. 運営者は、会員が本規約に違反し、又は本サービスの正常な運営を妨害した場合、違反の程度に応じて、警告、 コンテンツの削除、機能の制限、一時利用停止、永久利用停止等の措置を段階的に又は直ちに講じることができる。 第16条に該当する違反については、段階を経ずに直ちに永久利用停止とすることができる。
  2. 運営者は、利用制限の措置を講じる場合、その理由及び内容を会員に通知する。ただし、緊急の措置が必要な場合は、 措置後に通知することができる。
  3. 会員は、利用制限の措置に対して異議を申し立てることができ、異議が正当であると認められる場合、運営者は直ちに 措置を解除する。
  4. 利用停止中は本サービスにログインすることができず、ログインを試みた際に利用停止の理由及び解除日が案内される。 利用停止中に退会した場合であっても利用停止期間は維持され、その期間中（最長1年）は同一のソーシャルアカウントで 再登録することはできない（第7条第6項）。
